## 1. BOOTSTRAP

### 1.1. INSTALLATION

```
npm install react-bootstrap bootstrap
```
### 1.2. BOOTSTRAP BREAKPOINTS
```
<!-- Breakpoints -->

    --bs-breakpoint-xs: 0;
    --bs-breakpoint-sm: 576px;
    --bs-breakpoint-md: 768px;
    --bs-breakpoint-lg: 992px;
    --bs-breakpoint-xl: 1200px;
    --bs-breakpoint-xxl: 1400px;
}

```
