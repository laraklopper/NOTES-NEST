# GLOSSARY

Abbreviations and terms used across this application and its documentation.

| **ABBREVIATION** | **TERM** | **EXPLANATION** |
|-------| -------| -------|
|`API`| **APPLICATION PROGRAMMING INTERFACE** | A set of rules and endpoints that allow different software systems to communicate. In this app the Express backend exposes a REST API that the React frontend calls to register and authenticate users, translate text, and manage translation history and favourites. The backend in turn calls the third-party Langbly translation API. |
|`ARIA`| **ACCESSIBLE RICH INTERNET APPLICATIONS** | A W3C specification that adds semantic attributes to HTML elements so assistive technologies can interpret dynamic content correctly. |
|`AT`| **ASSISTIVE TECHNOLOGIES** | Software and hardware (e.g. screen readers, braille displays) that help users with disabilities access digital content. |
|`ATAG`| **AUTHORING TOOL ACCESSIBILITY GUIDELINES** | W3C guidelines covering the tools used to *create* web content, ensuring both the tool itself and the content it produces are accessible. A companion standard to WCAG and UAAG. |
|`BSON`| **BINARY JSON** | A binary-encoded serialisation format for JSON-like documents used natively by MongoDB. BSON supports additional data types not present in standard JSON, such as `Date` and `ObjectId`. MongoDB stores all documents internally as BSON and converts to/from JSON when communicating with application code. |
|`CLI`| **COMMAND LINE INTERFACE** | A text-based interface for interacting with software via typed commands. Used throughout this project with tools like `npm`, `node`, and `git`. |
|`CORS`| **CROSS-ORIGIN RESOURCE SHARING** | A browser security mechanism that controls which external domains are permitted to make requests to a server. Configured in the Express backend via the `cors` package so the React frontend can call the API. |
|`CRA`| **CREATE REACT APP** | The React build toolchain (`react-scripts`) the client is generated with. It supplies the development server, the `proxy` setting that forwards API calls to the server, and the production build, without hand-configuring a bundler. |
|`CRUD`| **CREATE, READ, UPDATE, DELETE** | The four fundamental database operations. This app performs CRUD on translation history, saved favourites, user accounts and user settings stored in MongoDB. |
|`CSP`| **CONTENT SECURITY POLICY** | An HTTP response header that instructs the browser which sources of content (scripts, styles, images) are permitted to load. Helps prevent XSS attacks. Applied in this application via the `helmet` package. |
|`CSS`| **CASCADING STYLE SHEETS** | The language used to describe the visual presentation of HTML documents. |
|`CSV`| **COMMA-SEPARATED VALUES** | A plain-text format for representing tabular data where values are separated by commas. Used in this application to export translation history and favourites, generated server-side with the `csv-stringify` package. |
|`DNS`| **DOMAIN NAME SYSTEM** | The internet's naming system that translates human-readable domain names into IP addresses. MongoDB Atlas connection strings use DNS SRV records via the `mongodb+srv://` scheme to automatically discover replica set members. |
|`DOM`| **DOCUMENT OBJECT MODEL** | The browser's in-memory tree representation of an HTML page. React manages the DOM efficiently through a virtual DOM. |
|`ENV`| **ENVIRONMENT VARIABLE** | A key/value setting read at runtime from `process.env` rather than hard-coded in the source. Loaded from a `.env` file by the `dotenv` package and excluded from version control. This application reads `PORT`, `DATABASE_URL`, `DATABASE_NAME`, `JWT_SECRET_KEY`, `LANGBLY_API_KEY` and `CLIENT_ORIGIN` (the origin CORS allows to send the auth cookie; defaults to `http://localhost:3000`). |
| `gRPC`| **GOOGLE REMOTE PROCEDURE CALL** | A high-performance framework built on HTTP/2 that uses compact binary data, making it ideal for fast communication between internal microservices |
|`HMAC`| **HASH-BASED MESSAGE AUTHENTICATION CODE** | A hash computed with a secret key, proving a message was produced by someone holding that key and has not been altered since. The mechanism behind the `HS256` signature on this application's JWTs. |
|`HS256`| **HMAC USING SHA-256** | The signing algorithm set in `authRoutes.js` when issuing JWTs. The token is signed with the server-side `JWT_SECRET_KEY`, so a token altered by the client fails verification. |
|`HTML`| **HYPERTEXT MARKUP LANGUAGE** | The standard markup language for structuring content on the web. |
|`HTTP`| **HYPERTEXT TRANSFER PROTOCOL** | The protocol used to transfer data between a client and a server over the web. |
|`HTTPS`| **HYPERTEXT TRANSFER PROTOCOL SECURE** | The encrypted version of HTTP, using TLS to protect data in transit. Required for production deployments. |
|`IANA`| **INTERNET ASSIGNED NUMBERS AUTHORITY** | The organisation responsible for maintaining global internet standards, including the official timezone database. IANA timezone identifiers (e.g. `Africa/Johannesburg`) are used in `client/src/utilFunctions/dateFunctions.js` to display stored timestamps in the user's local time. |
|`IP`| **INTERNET PROTOCOL** | The fundamental communication protocol that routes data across networks. Each device is assigned an IP address. In this app, IP addresses are used by the rate limiters to track and restrict repeated requests from individual clients. |
|`ISO`| **INTERNATIONAL ORGANIZATION FOR STANDARDIZATION** | An international standards body. ISO 639-1 defines the 2-letter language codes (e.g. `en`, `af`, `fr`) this application uses to identify source and target languages; the static list in `server/util/languageData.js` maps those codes to language names. A handful of codes in the language list fall outside ISO 639-1 — three-letter codes such as `ceb` and region-qualified codes such as `zh-TW` and `en-GB`. |
|`JAWS`| **JOB ACCESS WITH SPEECH** | A widely used commercial screen reader for Windows. One of the assistive technologies the interface is expected to work with. |
|`JS`| **JAVASCRIPT** | The programming language of the web, used here for both the React frontend and the Node.js/Express backend. |
|`JSON`| **JAVASCRIPT OBJECT NOTATION** | A lightweight, human-readable data format used to exchange data between the frontend and backend API. |
|`JSX`| **JAVASCRIPT XML** | A React syntax extension that lets you write HTML-like markup inside JavaScript files. |
|`JWT`| **JSON WEB TOKEN** | A compact, signed token used to securely transmit authentication information between client and server without storing session state. Issued on login by `authRoutes.js` with a one hour expiry, and required by every route except `/auth` and the guest translation endpoints. |
|`MERN`| **MONGODB, EXPRESS.JS, REACT, NODE.JS** | The full-stack JavaScript architecture this application is built on. |
|`MIME`| **MULTIPURPOSE INTERNET MAIL EXTENSIONS** | A standard that extends the format of email and web content to support character sets other than ASCII, as well as attachments such as images and files. On the web, MIME types (e.g. `application/pdf`, `image/png`) describe the nature and format of a document or file. Used in this application by `uploadMiddleware.js`, which accepts an uploaded document only when its MIME type is `application/pdf`. |
|`MT`| **MACHINE TRANSLATION** | Translation performed automatically by software rather than by a person. Supplied in this application by the Langbly translation API, which the server calls through `services/langblyClient.js`. |
|`MVC`| **MODEL VIEW CONTROLLER** | An architectural pattern that separates an application into three layers: data (Model), UI (View), and business logic (Controller). |
|`NoSQL`| **NOT ONLY SQL / NON-RELATIONAL DATABASE** | A class of database that stores data in formats other than the traditional relational (tabular) model. MongoDB, used in this application, is a document-oriented NoSQL database that stores records as JSON-like BSON documents. |
|`NPM`| **NODE PACKAGE MANAGER** | The default package manager for Node.js, used to install and manage project dependencies. |
|`NVDA`| **NONVISUAL DESKTOP ACCESS** | A free, open-source screen reader for Windows, commonly used alongside JAWS when testing an interface for accessibility. |
|`ODM`| **OBJECT DOCUMENT MAPPER** | A library (Mongoose in this project) that maps JavaScript objects to MongoDB documents, providing schema validation and query helpers. |
|`PDF`| **PORTABLE DOCUMENT FORMAT** | A fixed-layout document format that preserves a file's appearance across devices and applications. The only file type the document translator accepts: uploads are limited to a 5 MB `.pdf` by `uploadMiddleware.js`, held in memory rather than written to disk, and their text is extracted by `services/documentParser.js` using the `pdf-parse` package. |
|`POUR`| **PERCEIVABLE, OPERABLE, UNDERSTANDABLE, ROBUST** | The four principles WCAG is organised around: users can perceive the content, operate every feature, understand what is presented, and rely on it working with browsers and assistive technologies. |
|`RBAC`| **ROLE BASED ACCESS CONTROL** | A security model that restricts system access based on a user's assigned role. In this application, the `admin` boolean field on the User model controls whether a user can access admin-only routes and actions, enforced on the client by `ProtectedAdminRoute`. Regular users have standard access; admin users have elevated privileges. |
|`REGEX`| **REGULAR EXPRESSION** | A sequence of characters that defines a search or match pattern. Used in this application to validate email format, enforce password strength requirements, and normalise the line breaks in text extracted from a PDF. |
|`REST (API)`| **REPRESENTATIONAL STATE TRANSFER** | An architectural style for APIs that uses standard HTTP methods (GET, POST, PUT, PATCH, DELETE) and stateless communication. |
|`RFC`| **REQUEST FOR COMMENTS** | A formal document published by the IETF (Internet Engineering Task Force) that defines internet standards and protocols. In this application, RFC 6585 defines the `429 Too Many Requests` HTTP status code returned by rate limiters when a client exceeds its allowed request quota. |
|`RWD`| **RESPONSIVE WEB DESIGN** | A design approach that ensures a web application looks and works correctly across different screen sizes and devices. |
|`SHA`| **SECURE HASH ALGORITHM** | A family of cryptographic hash functions standardised by NIST. This application uses SHA-256 as the hash inside the `HS256` HMAC that signs and verifies JWTs, so a token cannot be forged or modified without the server's secret key. |
| `SOAP` | **SIMPLE OBJECT ACCESS PROTOCOL**| A protocol used for exchanging structured information between applications and uses XML-based messages.|
|`SPA`| **SINGLE PAGE APPLICATION** | A web app that loads a single HTML page and dynamically updates content without full page reloads. React, with `react-router-dom`, enables this pattern. |
|`SRV`| **SERVICE RECORD** | A type of DNS record that specifies the hostname and port of a network service. MongoDB Atlas uses SRV records via the `mongodb+srv://` scheme to provide automatic discovery of replica set members without hardcoding IP addresses. |
|`SVG`| **SCALABLE VECTOR GRAPHIC** | An XML-based vector image format that scales without loss of quality at any resolution. Used in this application for the `lucide-react` interface icons. |
|`TLS`| **TRANSPORT LAYER SECURITY** | A cryptographic protocol that secures communication over a network by encrypting data in transit. The foundation of HTTPS. |
|`TTS`| **TEXT-TO-SPEECH** | Technology that reads written text aloud as synthesised speech. Reserved as a future feature by the `voiceOutputEnabled` field on the settings schema. |
|`UAAG`| **USER AGENT ACCESSIBILITY GUIDELINES** | W3C guidelines for user agents — browsers, media players and other software that renders web content — covering how they should support assistive technologies. A companion standard to WCAG and ATAG. |
|`UI`| **USER INTERFACE** | The visual layer of an application — everything the user sees and interacts with. |
|`und`| **UNDETERMINED LANGUAGE** | The ISO 639-2 code for a language that could not be determined. Returned by the translation provider's detect endpoint when it cannot identify the text, and stored as the source language of a translation so the history record stays honest about what was detected. |
|`URI`| **UNIFORM RESOURCE IDENTIFIER** | A string that uniquely identifies a resource. A URL is a specific type of URI that includes a network location. The MongoDB connection URI is built from the cluster URL and database name held in the `.env` file. |
|`URL`| **UNIFORM RESOURCE LOCATOR** | The full web address used to locate a specific resource, e.g. `http://localhost:3001/translate`. |
|`UTC`| **COORDINATED UNIVERSAL TIME** | The global time standard that local timezones are expressed as offsets from. Timestamps are stored and exported in UTC (via `toISOString()` in `exportRoutes.js`) and converted to the display timezone in the client. |
|`UX`| **USER EXPERIENCE** | The overall quality of a user's interaction with an application, encompassing usability, accessibility, and satisfaction. |
|`W3C`| **WORLD WIDE WEB CONSORTIUM** | The international standards body that develops and maintains core web technology specifications, including HTML, CSS, ARIA, and WCAG. |
|`WAI`| **WEB ACCESSIBILITY INITIATIVE** | A W3C programme that develops standards and guidelines (including WCAG and ARIA) to make the web accessible to people with disabilities. |
|`WCAG`| **WEB CONTENT ACCESSIBILITY GUIDELINES** | A set of W3C guidelines that define how to make web content accessible to people with disabilities. WCAG 2.1 (AA) is the widely adopted standard. |
|`XLSX`| **EXCEL OPEN XML SPREADSHEET** | The file format used by Microsoft Excel for storing spreadsheet data. Supported alongside CSV for exporting translation history and favourites, generated server-side with the `xlsx` package. |
|`XML`| **EXTENSIBLE MARKUP LANGUAGE** | A markup language that defines rules for encoding documents in a format that is both human-readable and machine-readable. Several technologies used in this application are XML-based: SVG uses XML for vector graphics, and JSX borrows XML-like syntax for writing React component markup. |
|`XSS`| **CROSS SITE SCRIPTING** | A security vulnerability where an attacker injects malicious scripts into web pages viewed by other users. Prevented by sanitising user input and using Content Security Policy headers. |
